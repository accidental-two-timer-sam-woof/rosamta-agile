# AI usage log

Add one file each time AI is used, numbered, for example `01-story-generation.md`.

## Format

```markdown
# <number> <topic>

- Date:
- Who:
- Tool and model:
- Purpose:

## Prompt

## AI output (verbatim)

## Accepted and rejected

| Item | Decision | Reason | Approved by |
| --- | --- | --- | --- |

## Where the AI was wrong

## Time saved or lost
```
