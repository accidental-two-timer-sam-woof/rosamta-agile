# Daily records

Add one file per day (or every two or three days), named by date, for example `2026-11-10.md`. AI may summarize the board activity first; the Scrum Master then edits it.

```markdown
# Daily record 2026-11-10

| Member | Done | Next | Blockers |
| --- | --- | --- | --- |
|  |  |  |  |

- Related stories: #
- AI summary used: yes / no. What we changed:
```
