# UML

Diagrams are written in Mermaid, which GitHub renders directly. One diagram per file:

- `use-case.md`: use case diagram
- `class.md`: class diagram (domain model)
- `sequence-apply.md`: sequence diagram of the apply flow
- `activity.md`: activity diagram

AI-drafted diagrams go through PR review, and what we changed is recorded in `docs/ai-log/`.
